## 上下文完整性检查

生成 PRP 前必须能回答：

1. 这一步改变谁能观察到的什么行为？
2. 哪些现有行为必须保持？
3. 哪些协议、表、线程、对象或 UI 会被触及？
4. 哪些文件是直接生产者、消费者和测试？
5. 成功、失败、边界、重复和恢复行为是什么？
6. 用户授权到设计、生产代码、测试、Git 的哪一层？
7. 用哪些新鲜命令和人工观察证明完成？
