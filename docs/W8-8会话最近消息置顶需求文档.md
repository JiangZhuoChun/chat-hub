# W8-8 会话最近消息置顶需求文档

## 1. 目标与非目标

### 目标

当某个会话成功写入一条完整 `ChatMessage` 后，将对应的会话项移动到 `conversationList`
顶部。该规则适用于本地发送、当前会话收到消息、非当前会话收到消息，以及防御性补建后写入消息的路径。

### 非目标

- 不修改 TCP 协议、`ChatMessage`、服务端、消息时间或消息状态；
- 不新增会话排序缓存，不对 `m_conversations` 的 `QHash` 排序；
- 不根据 `QListWidgetItem::text()` 排序或查找；显示文本可随未读数、预览、时间变化；
- 点击会话、清除未读数、确认帧、失败帧或仅刷新显示时，不改变会话位置；
- 不实现置顶、固定联系人、拖拽排序或跨重启持久化排序。

## 2. 业务规则

1. 新消息先写入 `m_conversations[peer]`，再确保会话项存在，随后把该项移动到第 0 行，最后刷新该项文本。
2. 会话项的稳定身份始终读取 `item->data(Qt::UserRole).toString()`；`item->text()` 仅用于显示，绝不参与定位。
3. 若 `peer` 为空或列表中找不到对应项，移动函数安全返回，不创建消息模型，也不修改其他会话顺序。
4. `takeItem()` 取出的 `QListWidgetItem*` 必须立刻交给 `insertItem()`，所有权重新回到列表；不得手动 `delete`。
5. 只在“新消息已写入模型”的路径调用移动函数。`markConversationRead()` 和 `refreshConversationItem()` 只更新显示，不负责排序。

## 3. 数据与职责边界

| 数据或对象   | 唯一来源/所有者                  | 职责                  |
|---------|---------------------------|---------------------|
| 完整消息    | `m_conversations`         | 判断一条新消息是否已进入本地会话模型  |
| 会话项稳定身份 | `Qt::UserRole`            | 在控件列表中定位正确联系人       |
| 会话项显示文本 | `QListWidgetItem::text()` | 显示名称、未读数、时间和预览，不作为键 |
| 会话视觉顺序  | `ui->conversationList`    | 保存和展示当前置顶顺序         |

## 4. 函数清单

| 模块           | 函数签名                                                  | 可见性        | 职责                            | 错误行为              |
|--------------|-------------------------------------------------------|------------|-------------------------------|-------------------|
| `MainWindow` | `void moveConversationItemToTop(const QString& peer)` | private    | 按 `UserRole` 找到会话项并移动到列表第 0 行 | 空 peer 或找不到项时安全返回 |
| `MainWindow` | `void ensureConversationItem(const QString& peer)`    | private，既有 | 在需要时创建会话项                     | 空 peer 时安全返回      |
| `MainWindow` | `void refreshConversationItem(const QString& peer)`   | private，既有 | 刷新名称、未读数、时间和预览                | 只更新显示，不排序         |

本轮不新增成员变量。

## 5. 调用流程与错误分支

1. 收到或发送一条完整消息，写入 `m_conversations`。
2. 调用 `ensureConversationItem(peer)`，保证列表项存在。
3. 调用 `moveConversationItemToTop(peer)`；按 `UserRole` 定位，找到后 `takeItem()` 再 `insertItem(0, item)`。
4. 调用 `refreshConversationItem(peer)`，更新置顶项的两行文本。
5. 若 `peer` 为空或未找到会话项，移动步骤安全结束；现有消息渲染、未读数和错误处理不受影响。

## 6. 验收标准

- 向 Bob 发送消息后，Bob 会话移动到顶部；向 Carol 发送消息后，Carol 移动到顶部。
- Bob 在非当前会话发来消息时，Bob 移动到顶部且未读数正确递增。
- 当前会话收到消息后，该会话同样置顶，但不会错误增加未读数。
- 点击某会话清除未读数、认证确认或发送失败状态更新时，列表顺序不变化。
- 会话标题即使显示 `(N)`、时间和预览，仍能通过 `UserRole` 正确置顶。
- 构建通过，既有会话切换、未读数、预览和时间摘要功能不回退。
