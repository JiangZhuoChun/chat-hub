# W10 交付稳定性故障记录

> 范围：本文件仅记录 W10 已实现行为的可复现故障、保护机制和回归证据。
>
> 安全边界：所有步骤使用临时目录、临时端口和测试 JWT；不记录真实令牌、密码、密钥、完整聊天正文或真实数据库数据。

## 1. 数据库不可用：`database_unavailable`

- 临时环境：`ScopedTestDirectory` 创建独立目录，并在其中把 `database-is-a-directory` 创建为目录而非 SQLite 文件。
- 触发步骤：以该目录作为 `Server` 的数据库路径启动；认证 Alice、Bob；Alice 向在线的 Bob 发送聊天帧。
- 预期与实际：SQLite 无法打开该路径，Alice 收到 `type=error`、`scope=chat`、`code=database_unavailable`，并保留原始
  `local_id`。Alice 和 Bob 随后均仍可 `ping/pong`。
- 根因：数据库路径指向目录，SQLite 无法将其作为数据库文件打开。
- 修复/保护机制：`MessageRepository::open()` 失败后，`Server::m_database_available` 为 false；`routeChat()`
  在写入前返回固定错误，不尝试持久化，也不关闭无关会话。
- 自动化覆盖：`online_users_integration_test` 的 `testDatabaseUnavailableKeepsAuthenticatedSessionsAlive()`。
- 回归命令：
  `ctest --test-dir D:\CppLearn\chathub\cmake-build-debug --output-on-failure -R online_users_integration_test`。

## 2. 未认证连接超时：`authentication_timeout`

- 临时环境：`ScopedTestDirectory` 与本机临时端口启动真实 Server。
- 触发步骤：原始 TCP 客户端建立连接，仅发送 `ping`，不发送认证帧。
- 预期与实际：非认证 `ping` 不延长认证截止；约 5000ms 后客户端收到 `type=error`、`scope=auth`、`code=authentication_timeout`
  ，然后连接关闭。
- 根因：连接已经建立，但在认证期限内没有形成可信用户身份。
- 修复/保护机制：`Session` 的 `steady_timer` 到期后将终态裁决投递到 Server strand；只有仍未准入的 Session 才会被拒绝，错误帧写完后关闭。
- 自动化覆盖：`online_users_integration_test` 的 `testUnauthenticatedPingTimesOut()`；运行配置子进程测试也覆盖自定义
  `1000ms` 截止。
- 回归命令：
  `ctest --test-dir D:\CppLearn\chathub\cmake-build-debug --output-on-failure -R "online_users_integration_test|server_process_config_test"`。

## 3. 第 89 名用户准入拒绝：`online_snapshot_capacity_exceeded`

- 临时环境：`ScopedTestDirectory`、临时数据库和临时端口；用户名均为 20B 合法值。
- 触发步骤：依次认证 88 名用户，再认证第 89 名候选用户。
- 预期与实际：前 88 名用户保留完整快照；候选连接收到 `type=error`、`scope=online_users`、
  `code=online_snapshot_capacity_exceeded` 和 `max_users=88`，随后关闭。任意已有用户断开后，新的第 88 名可再次准入。
- 根因：89 个最大长度用户名的完整快照会超出单帧 2048B 合同，不能静默截断或发送部分名单。
- 修复/保护机制：Server 在修改认证映射和广播前计算候选快照；超过 `kMaxOnlineUsersSnapshotCount` 时拒绝候选会话，保持既有在线状态不变。
- 自动化覆盖：`online_users_integration_test` 的 `testCapacityBoundaryAndRecovery()`。
- 回归命令：
  `ctest --test-dir D:\CppLearn\chathub\cmake-build-debug --output-on-failure -R online_users_integration_test`。
