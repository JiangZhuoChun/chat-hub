# ChatHub V1 — 架构与规划文档

> 2026-08-03 | W6 骨架集成 | 目标：10 月中前交付可演示的聊天系统

> 本轮代码结构整理：协议常量与聊天模型集中管理；Qt 客户端、UI 与服务端会话的函数和成员按职责分组，源码目录保持现状。

---

## 一、目标架构

```
┌─────────────────────────────────────────────────────────┐
│  Qt 6 客户端 (client-qt)                                 │
│  登录/注册页                                             │
│  ──HTTP──► auth-service (Node.js Express)               │
│              │ 注册/登录/JWT 签发                        │
│              └─ users.sqlite                            │
│                                                         │
│  ──TCP 长连接（携带 JWT）──► chat-server (C++ asio)     │
│                              │ Session 管理/广播         │
│                              ├─ 协议分帧(8字节头)        │
│                              ├─ JWT 验签                │
│                              └─ chat.sqlite (W9)        │
└─────────────────────────────────────────────────────────┘
```

## 二、技术选型（已确认）

| 组件   | 选择                | 说明                                           |
|------|-------------------|----------------------------------------------|
| 客户端  | Qt 6.11 Widgets   | QNetworkAccessManager + QTcpSocket           |
| 认证服务 | Node.js + Express | 复用 week5 已验证代码                               |
| 聊天服务 | C++17 + 独立 asio   | 复用 week3 已验证 Server/Session/FrameDecoder     |
| 存储   | SQLite            | auth 用 better-sqlite3，chat 用官方 sqlite3 C API |
| 认证   | JWT               | 客户端带 token，chat-server 验签                    |
| 构建   | CMake + MinGW     | 独立 asio 无需 Boost                             |

## 四、模块职责

| 模块            | 负责                               | 不负责    |
|---------------|----------------------------------|--------|
| client-qt     | UI、调 Auth HTTP、TCP 连 chat-server | 协议实现细节 |
| auth-service  | 注册/登录/JWT                        | 聊天逻辑   |
| chat-server   | TCP 连接/分帧/广播/JWT验签               | UI     |
| protocol (共享) | 8字节协议头编解码                        | 业务逻辑   |
