# W8-3 气泡重试回调最小捕获需求文档

## 1. 目标与非目标

### 目标

将失败气泡的重试 Lambda 从“捕获完整 `ChatMessage`”改为“仅捕获 `local_id`”。重试行为、消息状态和现有协议保持不变。

### 非目标

- 不修改 TCP 协议、`ChatMessage` 结构、消息状态机或重试流程；
- 不修改 `onRetryClicked()` 的职责和签名；
- 不调整 UI 样式、气泡布局或会话存储结构；
- 不做其他重构。

## 2. 模块与依赖

- 影响模块：`client-qt/MainWindow` 的消息气泡渲染辅助函数。
- 依赖方向：`appendMessageBubble()` 读取 `ChatMessage` → 创建 `QToolButton` → 点击回调调用 `onRetryClicked(local_id)` →
  UI 查询已有会话模型。
- 数据所有权：Lambda 保存自己的 `QString local_id` 副本；不保存会话容器元素引用，也不保存完整 `ChatMessage`。

## 3. 正常与错误流程

1. `appendMessageBubble(const ChatMessage& message)` 创建失败重试按钮。
2. 从 `message.local_id` 复制一个字符串给 Lambda。
3. 用户点击按钮，Lambda 调用 `onRetryClicked(local_id)`。
4. `onRetryClicked()` 按 ID 查找既有完整消息；找不到时显示提示并安全返回。

错误情况下，空 ID 或未知 ID 仍由既有 `onRetryClicked()` 处理；本次不新增错误分支。

## 4. 函数清单

| 模块           | 函数签名                                                   | 可见性          | 职责                 | 输入/输出        | 错误行为         | 调用方                           |
|--------------|--------------------------------------------------------|--------------|--------------------|--------------|--------------|-------------------------------|
| `MainWindow` | `void appendMessageBubble(const ChatMessage& message)` | private      | 创建气泡和失败重试按钮        | 完整消息 / UI 控件 | 不处理消息查找错误    | `renderCurrentConversation()` |
| `MainWindow` | `void onRetryClicked(const QString& local_id)`         | private slot | 通过稳定 ID 找到并重新发送原消息 | ID / 状态变化、提示 | 空或未知 ID 安全返回 | 重试按钮 Lambda                   |

## 5. 验收标准

- Lambda 捕获列表中不再按值捕获完整 `message`。
- Lambda 只向 `onRetryClicked()` 传入原 `local_id`。
- 正常消息展示、失败红点显示和点击重试行为不变。
- `cmake --build build --parallel 2` 通过。
