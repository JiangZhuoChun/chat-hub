# W8-7 会话时间摘要需求文档

## 1. 目标与非目标

### 目标

在左侧会话列表每项第一行的联系人名称后显示最后一条消息的时间摘要。时间只从完整 `ChatMessage::send_at` 推导，不新增缓存，也不修改消息时间。

示例：

```text
Bob (2) · 10:30
今晚一起复习吗？
```

### 非目标

- 不修改 TCP 协议、`ChatMessage`、服务端或消息排序；
- 不实现相对时间（如“5 分钟前”）、定时自动刷新、会话置顶或自定义 `QListWidgetItem`；
- 不改变 W8-6 的未读数、预览、点击清零、气泡渲染或重试逻辑；
- 不在列表中显示精确秒数、消息 ID 或发送者 ID。

## 2. 时间规则与边界

`ChatMessage::send_at` 存储为 UTC。展示前必须与当前时间统一转换为本地时间后再比较日期。

| 条件                | 时间摘要         |
|-------------------|--------------|
| `send_at` 无效      | 空字符串         |
| 与当前本地日期相同         | `HH:mm`      |
| 当前日期的前一天          | `昨天`         |
| 与当前本地年份相同但不是今天/昨天 | `MM-dd`      |
| 其他年份              | `yyyy-MM-dd` |

第一行组合规则：有未读数时为 `peer (N) · time_text`；无未读数时为 `peer · time_text`。若 `time_text` 为空，则不显示分隔符
` · `。

## 3. 数据与职责边界

| 数据     | 唯一来源                           | 责任               |
|--------|--------------------------------|------------------|
| 最后一条消息 | `m_conversations[peer].last()` | 提供 `send_at` 与正文 |
| 当前时间   | 调用方传入的 `now`                   | 使格式化函数可独立测试      |
| 时间摘要   | `formatConversationTime()` 返回值 | 纯展示数据，不写回模型      |
| 会话项文本  | `refreshConversationItem()`    | 聚合名称、未读数、时间与预览   |

## 4. 函数清单

| 模块           | 函数签名                                                                                    | 可见性     | 职责                    | 错误行为                       |
|--------------|-----------------------------------------------------------------------------------------|---------|-----------------------|----------------------------|
| `MainWindow` | `static QString formatConversationTime(const QDateTime& send_at, const QDateTime& now)` | private | 按统一的本地日期规则生成时间摘要      | `send_at` 无效返回空字符串         |
| `MainWindow` | `QString makeConversationTimeText(const QString& peer) const`                           | private | 读取指定会话最后消息的时间并调用格式化函数 | peer 无效、无会话、无消息或无效时间返回空字符串 |
| `MainWindow` | `void refreshConversationItem(const QString& peer)`                                     | private | 在既有名称/未读数/预览基础上组合时间摘要 | 空 peer 或找不到项安全返回           |

本轮不新增任何成员变量。

## 5. 正常与错误流程

1. 新消息写入 `m_conversations` 后，既有路径调用 `refreshConversationItem(peer)`。
2. 刷新函数取得摘要正文和时间摘要，组合第一行标题与第二行预览。
3. 点击会话清零未读后，调用同一刷新函数；只有 `(N)` 消失，时间与预览保持不变。
4. 无效时间不显示时间摘要，不阻止会话项、未读数或预览的显示。

## 6. 验收标准

- 今天的消息显示 `HH:mm`；昨天消息显示“昨天”；同年较早消息显示 `MM-dd`；去年消息显示 `yyyy-MM-dd`。
- 无效 `send_at` 时不显示分隔符或空白占位，但仍显示联系人与预览。
- Bob 未读两条时显示 `Bob (2) · 时间`；点击 Bob 后变为 `Bob · 时间`，预览不丢失。
- 发送、当前会话接收、非当前会话接收均更新正确会话的时间摘要。
- 构建通过，W8-6 已验收能力不回退。

## 7. 实现与验收记录

### 实现结果

- `formatConversationTime()` 将消息时间和当前时间统一转换为本地时间后比较：今天显示 `HH:mm`，昨天显示“昨天”，同年较早日期显示
  `MM-dd`，跨年显示 `yyyy-MM-dd`。
- `makeConversationTimeText()` 只读查询 `m_conversations` 中指定会话的最后一条消息，并将其 `send_at`
  转为时间摘要；空联系人、未知会话、空消息或无效时间均返回空文本。
- `refreshConversationItem()` 只负责组装界面文本：第一行是“联系人 + 未读数 + 可选时间”，第二行复用既有预览；时间为空时不添加分隔符。
- 时间分隔符使用 `\u00B7`，避免源文件编码变化导致界面显示错误。

### 验收证据

- 人工验收通过：今天、昨天、同年较早日期、跨年和无效时间均按规则显示；未读数清零后只移除 `(N)`，时间和预览保持不变。
- `cmake --build build --parallel 2` 成功。
- `ctest --test-dir build --output-on-failure` 通过 2/2：`frame_decoder_test`、`jwt_demo`。
